# Catálogo de projetos

Todo item operacional deve declarar ou permitir inferir um `projeto`. O projeto define contexto, repositório, ambientes, convenções e destino do arquivo.

| Código | Projeto | QA | DEV | Arquivo |
|---|---|---|---|---|
| `nxgest` | Nxgest | [[03 Trabalho/QA/Nxgest/00 README|QA]] | [[03 Trabalho/DEV/Nxgest/00 README|DEV]] | [[05 Arquivo/Nxgest/00 README|Arquivo]] |
| `sogov` | SOGOV | [[03 Trabalho/QA/SOGOV/00 README|QA]] | [[03 Trabalho/DEV/SOGOV/00 README|DEV]] | [[05 Arquivo/SOGOV/00 README|Arquivo]] |

Quando um terceiro projeto entrar, crie sua entrada aqui e replique apenas os três índices de projeto; não copie o sistema inteiro.
