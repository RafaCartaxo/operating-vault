# Planos técnicos

Planos de construção e implementação do produto. Cada plano deve apontar para uma demanda em `03 Trabalho QA` (quando existir) e para sua execução em `04 Trabalho DEV/Execuções`.

## Diferença para QA

- `03 Trabalho QA/Planos de teste`: estratégia, cenários e cobertura de qualidade.
- `04 Trabalho DEV/Planos`: solução técnica, escopo de código e sequência de construção.
