## Objetivo

Criar o frontend React + Vite + TypeScript, responsivo e mobile-first, com a primeira tela de cadastro de despesa integrada ao backend Go.

## Critérios de aceite

- [ ] A aplicação abre em desktop e celular sem quebrar o layout.
- [ ] É possível preencher e enviar uma nova despesa.
- [ ] O frontend chama `POST /api/lancamentos`.
- [ ] Erros de validação da API aparecem de forma compreensível.
- [ ] Após sucesso, o usuário recebe confirmação clara.
- [ ] O fluxo está documentado e coberto por testes básicos.

## Estado

Execução DEV preparada para iniciar após a demanda QA fechar escopo, critérios de aceite, plano e casos de teste. O código do backend já está validado; o frontend ainda não foi iniciado.
