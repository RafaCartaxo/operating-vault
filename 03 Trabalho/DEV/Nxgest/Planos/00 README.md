# Planos técnicos

Planos de construção e implementação do produto. Cada plano deve apontar para uma demanda em `03 Trabalho/QA/Nxgest` (quando existir) e para sua execução em `03 Trabalho/DEV/Nxgest/Execuções`.

## Diferença para QA

- `03 Trabalho/QA/Nxgest/Planos de teste`: estratégia, cenários e cobertura de qualidade.
- `03 Trabalho/DEV/Nxgest/Planos`: solução técnica, escopo de código e sequência de construção.
