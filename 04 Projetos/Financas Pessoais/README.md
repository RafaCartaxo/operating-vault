# Finanças Pessoais

Projeto de uma aplicação local para registrar despesas, parcelas, recorrências, receitas e faturas com facilidade.

## Fontes oficiais

| Responsabilidade | Local | O que consultar |
|---|---|---|
| Desenvolvimento e execução | `operating-vault/` | tarefas, roadmap, status e decisões operacionais |
| Implementação | `financas-pessoais/` | código Go, frontend, API, banco, testes e planos técnicos |
| Dados e acompanhamento financeiro | `financas-vault/` | painel, meses, relatórios e fluxos de uso |

> O Operating Vault coordena o trabalho, mas não é o repositório do código nem a fonte dos dados financeiros.

## Objetivo inicial

Criar um fluxo funcional para cadastrar uma despesa e consultá-la no mês correto, usando backend Go, SQLite no desenvolvimento e API HTTP acessível por URL na implantação.
