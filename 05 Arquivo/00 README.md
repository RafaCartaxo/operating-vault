# 05 Arquivo

Cards concluídos/arquivados, separados por projeto. Cada pacote é movido de `03 Trabalho/QA/<projeto>/` quando ✅ no board.

- [[05 Arquivo/Nxgest/00 README|Nxgest]]
- [[05 Arquivo/SOGOV/00 README|SOGOV]]

Cada entrega arquivada mantém o histórico separado por fluxo:

```text
<tipo>/<ID>/
├── 00 README.md
├── QA/
└── DEV/
```

`QA` guarda bug/demanda, casos e validação. `DEV` guarda análise, plano de execução, implementação e code review.
