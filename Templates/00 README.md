# Templates

Modelos reutilizáveis do vault, separados por tipo de registro.

## Regra obrigatória

Todo artefato deve nascer copiando o template oficial correspondente. Depois da cópia, substitua placeholders e adapte o conteúdo ao projeto, preservando a estrutura, os campos, os headings, os callouts, as âncoras, as tabelas e os blocos de automação.

Não recrie um template do zero nem remova informações para “simplificar”. Se o modelo precisar mudar, altere primeiro este catálogo ou o template específico; em seguida, instancie os novos cards.
